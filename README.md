# vertical-farm-rl-mpc
This repo is dedicated to my master's thesis work on using reinforcement learning based model predictive control on a vertical farm. 


Plotting:

The default output of the code is a series of plots and a json-file containing the generated solutions.
Plots are automatically saved in the plots-folder under a directory corresponding to the name of the simulation being run.
Simulated runs are also stored as separate json-files in the simulations folder.
